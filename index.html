Password Manager

A zero-knowledge desktop password manager built with JavaFX and Maven, featuring a robust multi-tier cryptographic architecture. Engineered for maximum local security, the system leverages Argon2id for resilient master password hashing and an ephemeral-static X25519 DH key exchange to handle end-to-end credential encryption via ChaCha20-Poly1305. The intelligent key-wrapping mechanism ensures that changing the master password requires re-encrypting only the unique user keypair rather than the entire SQLite database, delivering high architectural efficiency, zero plaintext storage, and seamless on-demand decryption workflows.
